# Zadanie 2: Przekształcenie odnośnika w przycisk CTA

## Opis zadania
Przekształcenie elementu <a> w przycisk Call to Action z wykorzystaniem właściwości display: inline-block, dopełnienia padding, zaokrąglenia border-radius i cienia box-shadow.

## Treść do wpisania
* Nagłówek sekcji: "Specjalna Oferta Wdrożeniowa"
* Treść akapitu: "Skorzystaj z kompleksowego audytu infrastruktury IT Twojej firmy przed końcem bieżącego kwartału."
* Etykieta przycisku CTA: "Zamów Bezpłatny Audyt Teraz"

## Instrukcja wykonania krok po kroku
1. Przekształć odnośnik o klasie `.btn-cta` w element liniowo-blokowy (`display: inline-block`).
2. Nadaj mu parametry pudełka: `padding: 14px 28px`, brak podkreślenia (`text-decoration: none`), kolor tekstu biały (`#ffffff`), kolor tła `#2563eb`.
3. Ustaw `border-radius: 6px`, `font-weight: bold` oraz `cursor: pointer`.
4. Zastosuj subtelny cień `box-shadow: 0 4px 6px rgba(0, 0, 0, 0.1)`.
5. W stanie `:hover` zmień tło na `#1d4ed8` i powiększ cień na `0 8px 15px rgba(0, 0, 0, 0.15)`.
6. W stanie `:active` zmień tło na `#1e40af` i zmniejsz cień na `0 2px 4px rgba(0, 0, 0, 0.2)`.
