# Zadanie 4: Cienie pudełek (box-shadow) — przesunięcie, rozmycie i przezroczystość

## Cel ćwiczenia
Nauczysz się definiować cienie bloków o różnym stopniu rozmycia i natężenia z użyciem kanału alfa `rgba()`.

## Instrukcja wykonania
1. W pliku `style.css` dla wspólnej klasy `.karta-cienia` zdefiniuj szerokość `width: 280px;`, dopełnienie `padding: 20px;`, margines dolny `margin-bottom: 25px;`, tło białe oraz zaokrąglenie `border-radius: 10px;`.
2. Dla karty o klasie `.cien-subtelny` ustaw delikatny cień: `box-shadow: 0 2px 5px rgba(0, 0, 0, 0.08);`.
3. Dla karty o klasie `.cien-sredni` ustaw wyraźny cień: `box-shadow: 0 8px 16px rgba(0, 0, 0, 0.12);`.
4. Dla karty o klasie `.cien-gleboki` ustaw głęboki cień pływający: `box-shadow: 0 16px 32px rgba(0, 0, 0, 0.18);`.
5. Dla karty o klasie `.cien-kolorowy` ustaw błękitną poświatę cienia: `box-shadow: 0 10px 20px rgba(2, 132, 199, 0.3);`.

## Treść do wpisania
* Tytuł: `Skala Głębokości Cieni (Box-Shadow)`
* Karta 1: `Poziom 1 (Cień subtelny) — lekki cień bazowy dla kart informacyjnych w stanie spoczynku.`
* Karta 2: `Poziom 2 (Cień średni) — wyrazisty cień sugerujący uniesienie elementu ponad tło strony.`
* Karta 3: `Poziom 3 (Cień głęboki) — mocny cień stosowany dla okien modalnych i wyskakujących paneli.`
* Karta 4: `Cień akcentowy — kolorowy cień budujący nowoczesną poświatę w stylu brandu.`
